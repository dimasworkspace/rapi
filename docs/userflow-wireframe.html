Rapi Product Design

User Flow & Wireframe

Alur pengguna dan wireframe low-fidelity untuk fitur inti Rapi MVP — turunan langsung dari PRD. Fokus di struktur & urutan interaksi, belum masuk visual final (lihat UI Kit untuk versi high-fidelity).

Alur 1 — Catat Transaksi via Teks

Dari dashboard sampai transaksi tersimpan, target < 10 detik.

1Dashboard
Tap tombol tambah (FAB)
2Pilih Mode Input
Teks / Suara / Foto
3Ketik Kalimat
"makan siang 25rb"
4AI Parsing
Nominal + kategori otomatis
5Preview & Konfirmasi
User cek, edit jika perlu
6Tersimpan
"Kecatat! 💪" → balik ke dashboard

Alur 2 — Scan Struk (Foto)

Input via kamera/galeri, AI membaca struk sebelum user konfirmasi.

1Pilih Mode Foto
Dari layar tambah transaksi
2Foto / Upload Struk
Kamera langsung atau galeri
3AI Baca Struk
Ekstrak total & item
4Konfirmasi / Koreksi
User cek hasil scan
5Tersimpan
Tag "via foto struk"

Alur 3 — Tanya Rapi AI

Chat companion menjawab berdasarkan data transaksi user.

1Buka Tab Rapi AI
Dari bottom navigation
2Ketik Pertanyaan
"boros di mana bulan ini?"
3AI Ambil Konteks
Baca data transaksi user
4Jawaban Santai
Actionable, bahasa gaul
5Lanjut Follow-up
↻ tetap dalam sesi chat
